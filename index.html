🎙️ Gravar minha voz

A gravação usa o microfone e exige permissão do navegador. Em arquivos locais ou dentro do ChatGPT, o acesso pode ser bloqueado. Para funcionar de forma confiável, publique em HTTPS.

Aguardando gravação.

O navegador normalmente grava em WebM ou MP4, não MP3. Baixe o arquivo e envie-o nesta conversa para eu avaliar sua interpretação.

Como instalar no Xiaomi

Por enquanto este é um arquivo HTML, não um APK. Após publicar em HTTPS com os arquivos de instalação apropriados, será possível usar o menu do Chrome para instalar ou adicionar à tela inicial.

Para localizar o arquivo baixado: app Arquivos/Gerenciador de arquivos → Downloads, ou Chrome → ⋮ → Downloads. O ChatGPT pode abrir uma prévia sem salvar na pasta Downloads.
